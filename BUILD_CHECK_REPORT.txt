- GitHub Actions now runs verify_ps4_pkg.py on the produced .pkg and the associated
  pkg.gp4 and param.sfo BEFORE uploading the artifact.

  zero file count, missing GP4 entries, missing JBC in install mode, present JBC in diagnostic mode.

- Download of external dependencies (stb/OpenOrbis/JBC): this container has no internet access.
- Real PS4 startup, HTTP download, /data/pkg permissions, JBC load, BGFT install: no console.
- PKG structural validation alone cannot prove a package boots or installs successfully.

INSTALL INSTRUCTIONS
1. Replace/update the source files in your GitHub repository with the update ZIP contents,
   or replace entire repository with full-source ZIP, keeping your own catalog config.
2. Open GitHub Actions. Build Store and Installer independently. Keep diagnostic_without_jbc=false
   for the actual Installer (diagnostic builds cannot install PKGs).
3. A successful Actions run must end with verify_ps4_pkg.py saying STRUCTURE_OK and upload .pkg + .sha256.
4. Test on jailbroken PS4 with an authorized small homebrew .pkg. Check /data/pkg and
   /data/ChepGameStore/downloads and logs from both apps. Do not delete existing files.

These ZIPs contain source and build guard, NOT ready-made PS4 PKGs.
